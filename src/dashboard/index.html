Start commands

Use these when you are not relying on the Command Center Start Live Test button (for example SSH into a server, local terminal only, or CI). The web UI button runs the same entrypoint class as start.py but keeps logs attached to the dashboard process.

Run from the project root (folder that contains src/ and config/). On Windows, use py instead of python if needed.

Web UI: http://127.0.0.1:8081 — port is config/settings.yaml → dashboard.dashboard_port.

Paper trading + dashboard + AI

Default run: simulated orders (not --live). LLMs require ai.enabled: true, ai.live_inferencing: true, a non-empty provider_chain in config/settings.yaml, and provider keys in the repo .env or config/secrets.env. Use per-strategy use_ai in YAML to control which strategies call the model.

python start.py

Equivalent: python src/main.py --paper (see start.py at repo root).

Bot (paper / default dry-run)

python src/main.py
python src/main.py --paper

Dashboard only (no trading loop)

python src/main.py --dashboard-only

Live trading

Requires typing YES at the prompt. Use only when you intend real orders.

python src/main.py --live --confirm-live

Kill switch & resume

python src/main.py --emergency-stop
python src/main.py --resume-trading

Backtest (CLI)

Use this when the bot is not running, or as a separate scheduled job. If the bot is already running (any host — local, Docker, PaaS), use the Backtest tab instead so backtests run as a subprocess. Invoking main.py --backtest as the service entry point would replace the long-lived bot.

Entry point forwards to scripts/run_backtest.py; extra args go after --backtest.

python src/main.py --backtest --plan config/backtest_plan.yaml
python scripts/run_backtest.py --help

Unit tests

python -m pytest tests/ -q

Shutdown, cancel, and stop

When the bot is running, Command Center Start Paper Bot flips to Stop Bot and calls POST /api/live/shutdown for cooperative process shutdown. Pause Trading calls POST /api/live/stop to pause new entries while leaving the subprocess alive for scans, open-position monitoring, and dashboard metrics. When that pause is active the same button flips to Unpause Trading and clears data/KILL_SWITCH via POST /api/live/resume.

Foreground terminal

If you started the bot in a shell with logs attached: Ctrl+C once for cooperative shutdown (async tasks cancel, journals flush on exit). Reserve kill -9 for a wedged process only.

Emergency halt and resume

CLI copy-paste lives in Kill switch & resume under Start commands above: --emergency-stop and --resume-trading.
